Command-line reference¶

Terminal command¶

fsspec-browser [url] [options]

An omitted URL starts an interactive session prompt. Plain local paths and local-rs:// use the native local backend; s3:// and s3-rs:// use native S3. Other registered protocols use the Python fsspec bridge.

Option

Default

Meaning

-o, --storage-option KEY=VALUE

none

Repeated backend options.

--page-size

256

Entries fetched or revealed per page.

--preview-bytes

104857600

Raw preview bytes or decoded Arrow-memory budget.

--preview-rows

20

Rows per tabular preview page.

-h, --help

off

Command help.

Native S3 accepts endpoint_url, region, key / access_key_id, secret / secret_access_key, token / session_token, skip_signature, and allow_http. Bridged backends use their own storage-option names.

Terminal keys¶

Ctrl-A, then Left or Right, selects the browser or preview pane. Arrow, page, home, and end keys operate on the focused pane. With browser focus:

With preview focus, arrows scroll vertically or horizontally; page keys scroll vertically, and home/end move to the start/end. Ctrl-U and Ctrl-D scroll the preview vertically, and H and L scroll it horizontally from either pane.

Terminal previews and downloads¶

Local files can preview on selection; remote reads require p. Complete JSON is pretty-printed; truncated JSON stays raw. Arrow IPC (.arrow, .ipc) and Parquet (.parquet, .pq) render as tables through fsspec-data. Scrolling near the end loads another row page.

Downloads use the current working directory and a relative path derived from the selected URL.

Web previews and downloads¶

Selecting a file displays metadata. Preview or a double-click reads it. Directories expand on click and reveal more entries while scrolling. Refresh reloads the selected directory level.

Raw previews request at most --preview-bytes + 1 bytes to detect truncation. Complete .json previews are formatted. CSV, JSON/JSONL, Arrow IPC, Parquet, and database relations can render as tables. Arrow IPC and Parquet use row and decoded Arrow-memory bounds. The byte option is not a universal cap on backend traffic or on all structured decoders’ allocations.

SQL Preview is available when the filesystem provides query(). It accepts SELECT and WITH and wraps the query with a row limit.

Downloads are copied to --download-root. Target paths remove protocol parts and unsafe . or .. components. Metadata fields depend on the backend.
